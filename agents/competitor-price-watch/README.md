# Competitor Price Watch

Watch competitor product pages around the clock, read the live price from each one, keep the full price history, alert the moment a price moves past the configured threshold with context on what it means, and compile a pricing report on a regular cadence.

[![Add to Dispatcher](https://dispatcher.build/add-to-dispatcher.svg)](https://dispatcher.build/install?agent=competitor-price-watch)

It works out of the box on its defaults.

## Run it locally

```bash
pip install ../../dispatchkit-sdk -r ../../requirements-agents.txt
LLM_DISABLED=1 python3 -u main.py
```
