# Hacker News Radar

Watch Hacker News around the clock for the configured keywords — brands, products, competitors, topics — surface new mentions as they appear with points and thread context, flag hot threads immediately, and compile an AI brief of what the community is saying on a regular cadence.

[![Add to Dispatcher](https://dispatcher.build/add-to-dispatcher.svg)](https://dispatcher.build/install?agent=hn-radar)

It works out of the box on its defaults.

## Run it locally

```bash
pip install ../../dispatchkit-sdk -r ../../requirements-agents.txt
LLM_DISABLED=1 python3 -u main.py
```
