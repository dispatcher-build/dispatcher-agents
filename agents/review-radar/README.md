# Review Radar

Watch the business's Google reviews around the clock, surface every new review the moment it lands with a drafted owner reply, alert immediately on negative reviews and rating drops, and compile a reputation report on a regular cadence.

[![Add to Dispatcher](https://dispatcher.build/add-to-dispatcher.svg)](https://dispatcher.build/install?agent=review-radar)

## Before it works

Paste `GOOGLE_PLACES_API_KEY` into the agent's config.

## Run it locally

```bash
pip install ../../dispatchkit-sdk -r ../../requirements-agents.txt
LLM_DISABLED=1 python3 -u main.py
```
