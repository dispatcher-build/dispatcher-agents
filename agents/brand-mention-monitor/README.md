# Brand Mention Monitor

Watch Hacker News, Reddit and the news around the clock for the configured keywords — your brand, products and competitors — surface every new mention with context as it appears, flag high-engagement threads immediately, and compile an AI reputation brief of what people are saying on a regular cadence.

[![Add to Dispatcher](https://dispatcher.build/add-to-dispatcher.svg)](https://dispatcher.build/install?agent=brand-mention-monitor)

It works out of the box on its defaults.

## Run it locally

```bash
pip install ../../dispatchkit-sdk -r ../../requirements-agents.txt
LLM_DISABLED=1 python3 -u main.py
```
