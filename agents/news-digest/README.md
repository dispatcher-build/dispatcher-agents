# AI News Digest

Watch the configured news feeds around the clock, flag items matching alert keywords the moment they appear, and compile a themed executive digest of what matters on a regular cadence.

[![Add to Dispatcher](https://dispatcher.build/add-to-dispatcher.svg)](https://dispatcher.build/install?agent=news-digest)

It works out of the box on its defaults.

## Run it locally

```bash
pip install ../../dispatchkit-sdk -r ../../requirements-agents.txt
LLM_DISABLED=1 python3 -u main.py
```
